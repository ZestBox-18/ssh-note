# 0.2.0 中文界面重设计与默认配置读取

采用已选图标的深海军蓝、米白、薄荷绿配色，增加搜索列表、双列表单、配置实时预览、密钥文件路径选择、复制连接命令及底部保存栏。

启动默认只读加载 ~/.ssh/config，保存操作仍需用户点击。表单可直接保存；切换配置时先验证并保留有效草稿，修正字段增删导致行号移动后选择错误的问题。允许带点的别名；表单拒绝含空白或引号的新增值，复杂语法保留原文入口。

验证：macOS 15.7.5 arm64 Release 构建、核心四组检查、应用签名检查；GUI 示例端口变更即时更新预览、切换后草稿保留；隔离测试文件通过 Cmd+S 保存，产生原文备份。真实配置仅供应用启动读取，不用于写入测试。

未验证：Intel、其他 macOS、iCloud 跨设备同步、正式签名公证。无后端部署或数据库迁移。
回滚：保留升级前应用在 .ai-local/rollback/SSHNote-0.1.0.app；退出新版后可用旧应用替换。文件变更可通过自动备份恢复。
